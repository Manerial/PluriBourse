Contrôle de phase

Phase actuelle
Dépôt

Les bénévoles peuvent enregistrer les dépôts de vendeurs. Les caisses sont désactivées.

Prochaine phase
Vente

Les dépôts seront verrouillés. Les caisses bénévoles s'activeront sur tous les postes.

Passer en phase Vente

Les dépôts ne seront plus modifiables. Les caisses bénévoles s'activeront immédiatement sur tous les postes connectés.

warning Cette action est irréversible.
